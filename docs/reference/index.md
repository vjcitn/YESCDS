# Package index

## All functions

- [`brcamutSE`](https://github.com/vjcitn/YESCDS/reference/brcamutSE.md)
  : a SummarizedExperiment collecting BRCA mutations and colData from
  curatedTCGAData
- [`build_deck()`](https://github.com/vjcitn/YESCDS/reference/build_deck.md)
  : make a deck of cards with 52 elements and unicode symbols for suits
- [`build_simple_survival_curve()`](https://github.com/vjcitn/YESCDS/reference/build_simple_survival_curve.md)
  : utility for survival curve illustration
- [`build_surv_for_mut()`](https://github.com/vjcitn/YESCDS/reference/build_surv_for_mut.md)
  : use curatedTCGAData to produce survival time structure and mutation
  matrix for a TCGA tumor type
- [`canada_crude`](https://github.com/vjcitn/YESCDS/reference/canada_crude.md)
  : a data.frame with (rounded) crude rates of cancer as presented at
  https://www.statcan.gc.ca/en/dai/btd/asr
- [`cancer_map_app()`](https://github.com/vjcitn/YESCDS/reference/cancer_map_app.md)
  : use shiny for a simple cancer map, by type, for US
- [`cancer_map_usa()`](https://github.com/vjcitn/YESCDS/reference/cancer_map_usa.md)
  : simple function for site-specific map
- [`cancer_map_world()`](https://github.com/vjcitn/YESCDS/reference/cancer_map_world.md)
  : simple map of cancer rates world wide
- [`compare_tumors()`](https://github.com/vjcitn/YESCDS/reference/compare_tumors.md)
  : compare multiple tumor times with respect to survival
- [`do_new_surv()`](https://github.com/vjcitn/YESCDS/reference/do_new_surv.md)
  : utility for survival curve, alternate shape
- [`faces()`](https://github.com/vjcitn/YESCDS/reference/faces.md) : get
  faces of a collection of cards
- [`filter_woncan()`](https://github.com/vjcitn/YESCDS/reference/filter_woncan.md)
  : generate site-specific rate table
- [`full_house()`](https://github.com/vjcitn/YESCDS/reference/full_house.md)
  : test for full house
- [`get_hcc_spatial_path()`](https://github.com/vjcitn/YESCDS/reference/get_hcc_spatial_path.md)
  : retrieve or cache SingleCellExperiment data for spatial
  transcriptomics of HCC
- [`is_flush()`](https://github.com/vjcitn/YESCDS/reference/is_flush.md)
  : test for flush
- [`make_comparison()`](https://github.com/vjcitn/YESCDS/reference/make_comparison.md)
  : make an interactive histogram of rate ratios, or a scatterplot for
  rate comparisons, between two areas
- [`make_hist()`](https://github.com/vjcitn/YESCDS/reference/make_hist.md)
  : make an interactive histogram for a given cancer site, based on a
  rate table
- [`make_pair()`](https://github.com/vjcitn/YESCDS/reference/make_pair.md)
  : make interactive beeswarm or box plots for all cancer incidence
  rates in two areas
- [`map_app()`](https://github.com/vjcitn/YESCDS/reference/map_app.md) :
  use shiny to explore aspects of geographic mapping
- [`mass_cancer_map()`](https://github.com/vjcitn/YESCDS/reference/mass_cancer_map.md)
  : map cancer rates for selected sites to MA counties
- [`mass_map()`](https://github.com/vjcitn/YESCDS/reference/mass_map.md)
  : simple function to display HTML map of MA
- [`MA_cancer_rate_table()`](https://github.com/vjcitn/YESCDS/reference/MA_cancer_rate_table.md)
  : simple tables of confidence intervals for cancer incidence
- [`metabric`](https://github.com/vjcitn/YESCDS/reference/metabric.md) :
  a data.frame with clinical features of a breast cancer study
  (METABRIC) derived from cBioPortal
- [`one_pair()`](https://github.com/vjcitn/YESCDS/reference/one_pair.md)
  : test for one pair
- [`ordered_seg_cal()`](https://github.com/vjcitn/YESCDS/reference/ordered_seg_cal.md)
  : big display of ordered CIs for California Lung and Bronchus

- [`plotwci()`](https://github.com/vjcitn/YESCDS/reference/plotwci.md) :
  simple display of confidence intervals for cancer incidence
- [`plot_seer_trend()`](https://github.com/vjcitn/YESCDS/reference/plot_seer_trend.md)
  : plot the rate statistics over time for selected cancer sites and
  subgroups
- [`prostate_met_adeno`](https://github.com/vjcitn/YESCDS/reference/prostate_met_adeno.md)
  : a data.frame with clinical features of a metastatic prostate
  adenocarcinoma study
- [`SEER_2018`](https://github.com/vjcitn/YESCDS/reference/SEER_2018.md)
  : a data.frame with SEER estimates of cancer incidence for 2018
- [`show_5y_estimate()`](https://github.com/vjcitn/YESCDS/reference/show_5y_estimate.md)
  : utility for survival curve illustration: 5y survprob estimate sketch
- [`show_median_estimate()`](https://github.com/vjcitn/YESCDS/reference/show_median_estimate.md)
  : utility for survival curve illustration: median estimate sketch
- [`statcrunch_msa`](https://github.com/vjcitn/YESCDS/reference/statcrunch_msa.md)
  : geographic information from statcrunch.com on metropolitan
